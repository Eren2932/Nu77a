## Как проверить

Создай отдельную ветку и перенеси файлы архива в корень репозитория, включая
`.github`. Не удаляй свой `.git`, keystore и локальные настройки. В архиве нет
секретов подписи, Android SDK, Gradle или их кэшей.

При push в `main` / PR с Android-изменениями workflow Android запускает unit
тесты и собирает debug APK + APK инструментальных тестов. Для запуска тестов
на эмуляторе: Actions → Android → Run workflow → `run_ui_tests = true`.
Для ручного workflow на новой ветке GitHub может потребовать, чтобы версия
workflow с `workflow_dispatch` сначала существовала на default branch.

Локально, с JDK 17, Gradle 8.10.2 и Android SDK 35:

````bash
cd android
gradle :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest
# Только с подключённым устройством/эмулятором:
gradle :app:connectedDebugAndroidTest
````

Debug устанавливается отдельным пакетом `club.nuva.app.debug`. История release
в нём не появится — это не удаление данных. Для обновления существующего
release нужны прежний ключ, прежний applicationId и больший versionCode.
Ни имя пакета, ни схема базы v2 в этом изменении не менялись.

Старые `APPLY.patch`, `HOTFIX.patch`, `nuva-4.0-phase1.patch` сохранены как часть
исходного репозитория: **повторно применять их поверх этого ZIP не нужно**.

## Ограничения базы проекта

Текущий `ChatDraftStore` хранит текстовые сообщения в SQLite и не подключён к
сетевой доставке. `Sent` означает локальное сохранение, а не доставку на сервер.
В интерфейсе это обозначено явно. Наличие websocket-клиента и серверных
обработчиков само по себе не подключает их к этому экрану.

Не имитируются чужие сообщения, online, delivery/read receipts, push или
серверный бан. Карточка контакта открывается; локальное выключение звука и
копирование работают по существующей модели. Блокировка, голосовые/медиа,
серверное сохранение профиля и полноценный messaging sync не реализованы этим
UI-проходом. Экран редактора профиля по-прежнему сообщает, что сохранение
не подключено.

Правила и точные ссылки на изученный Telegram: `docs/UI-REDESIGN.md`.
