# План до релиза

**Дата релиза: 10 декабря 2026. Осталось 107 дней.**

Каждый спринт заканчивается устанавливаемым APK. Не «покажу когда допишу», а
каждые две недели — рабочее приложение в руках.

## Спринт 0 · Фундамент · 25 авг – 7 сен ✅ ЭТОТ КОД

- [x] Монорепа, Docker Compose, Caddy с авто-HTTPS
- [x] Go-сервер: конфиг, миграции, graceful shutdown
- [x] Регистрация, вход, JWT + ротация refresh, recovery-код
- [x] WebSocket-хаб с реконнектом и heartbeat
- [x] Android: Compose, экран входа, экран статуса, живой socket
- [x] Один keystore, релизная сборка падает без него
- [x] CI: тесты, debug APK, релизный APK по тегу, образ в GHCR
- [x] Smoke-тест всего цикла авторизации
- [ ] **Твоя часть:** VPS, домен, `make-keystore.sh`, первый тег `v0.1.0`

## Спринт 1 · Аккаунты и профили · 8 – 21 сен

- [ ] Аватары: загрузка, обрезка, отдача через сервер
- [ ] Профиль: имя, био, экран настроек
- [ ] Экран «Забыл пароль» с recovery-кодом
- [ ] Поиск людей по username
- [ ] Список активных сессий, отключение устройства
- [ ] Смена пароля с отзывом всех сессий
- [ ] Тёмная и светлая тема, русский и английский

**Итог:** можно зарегистрироваться, найти друг друга, настроить профиль.

## Спринт 2 · Ядро переписки · 22 сен – 12 окт (самый важный)

- [ ] Личные диалоги: создание, список с превью последнего сообщения
- [ ] Отправка и получение текста через WebSocket
- [ ] Локальный кеш на SQLite (Room), мгновенный старт офлайн
- [ ] Очередь исходящих: отправил в метро — уйдёт при появлении сети
- [ ] Идемпотентность по `client_id`: никаких дублей после обрыва
- [ ] Статусы: отправлено / доставлено / прочитано
- [ ] Индикатор «печатает»
- [ ] Пагинация истории по `seq`
- [ ] Ответы на сообщения, копирование, удаление

**Итог:** это уже настоящий мессенджер. Можно давать друзьям.

## Спринт 3 · Медиа и голос · 13 – 26 окт

- [ ] Фото и видео: загрузка, превью, полноэкранный просмотр
- [ ] Файлы любого типа до 100 МБ
- [ ] **Голосовые без лимита времени** (Opus, стриминговая загрузка)
- [ ] Плеер с волной, скорость 1×/1.5×/2×
- [ ] Прогресс загрузки, отмена, докачка
- [ ] Сжатие фото на клиенте перед отправкой

**Итог:** та самая боль Firebase закрыта окончательно.

## После 1.0 (не раньше)

| Версия | Что | Почему не сейчас |
|---|---|---|
| 1.1 | E2EE личных чатов на Signal Protocol | нужно делать правильно, не к дате |
| 1.1 | Веб-версия (React PWA) | см. `WEB.md` |
| 1.2 | Мультидевайс | самая дорогая фича мессенджера |
| 1.3 | Звонки (WebRTC + свой TURN) | отдельный сервер и отдельный месяц |
| 1.4 | Каналы, боты, стикеры | сначала база должна быть безупречной |
